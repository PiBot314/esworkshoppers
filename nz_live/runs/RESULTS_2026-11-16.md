## Bugs found and fixed today

1. **The board's clock jumped from 2023 to network time** after Wi-Fi came up, which made the live loop's "now" 3 years off until the next sync. The loop now offsets the API clock against a monotonic clock (`loop.ts`).
2. **Bun didn't exit on SIGTERM.** adapter-node closed the server but the process stayed alive, so the supervisor never restarted it (the dashboard was unreachable 07:57–07:59 and 10:00–10:03). It now exits after adapter-node's shutdown, or after 3 s (`hooks.server.ts`). Checked on the board: exited with rc=0 and restarted in 9 s.
3. **Chat:** the request to `llama-server` is retried once on a stale keep-alive connection (ECONNRESET). For a question, the first round's text is held back, and if no tool was called the model is asked once more. `max_tokens` lowered from 500 to 250 (the answers that ran away hit 500 at ≈ 6 tok/s, 80 s).
4. `LiveBar.svelte` (Live chip, flag banner with "Ask about it", demo fault buttons) was missing, so the dashboard didn't build. Written.
