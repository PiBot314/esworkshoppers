CSV format: 96 rows (15-min steps, oldest first) with a timestamp column (ISO, UTC or with offset) and one column per sensor feature, named exactly as in the template. Cyclic time features are computed from the timestamps; was_imputed columns default to 0. Optional row 97 = the reading that actually arrived next (used for the anomaly check).

Pipeline

trained FP32 ONNX (frozen, no retraining)
   │  AIMET 2.12: HTP v75 config · 1,024 calibration windows · range priors (LSTM h ∈ [−1,1], output +10 %)
   │              8-bit LSTM & dense weights · AutoQuant → AdaRound · 16-bit activations
   ▼
model.onnx + model.encodings ──► qnn-onnx-converter (overrides + calibration, LSTM expanded per step,
                                  I/O layout preserved) ──► qnn-model-lib-generator ──► lib*_w8a16.so
   ▼
